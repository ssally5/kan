# Kan website source

Extract the ZIP and open the folder in VS Code. To preview on Windows, open a terminal in this folder and run `py -m http.server 8000`. Visit http://localhost:8000 in your browser.

- account.js — registration, sign-in, and password recovery form fields
- app.js — navigation, account dialogs, and study interactions
- styles.css — layout and appearance
- data.js — sample Chinese dictionary
- index.html — website entry point

The frontend uses temporary demo data. Account authorization, password reset delivery, and persistent storage are future backend slices.
